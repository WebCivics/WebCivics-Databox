Provenance

Web Civics work — humanitarian ICT made concrete.

This Databox exists because of a long personal and community effort to build software for people and civic life. Timothy Charles Holborn’s technical work runs from 2000; Web Civics was established in 2014 for humanitarian ICT. The Databox layers — Smithy, exchange, evidence, IPMS, personal vault, CKAN — are that project’s work. They continue an open Solid / CSS commons (fork from 7.1.9 on a Node 20-class baseline, now maintained on Node ≥ 24), credited with thanks — dignity for this work does not require diminishing anyone else’s.

The primary story

Why Web Civics exists.

Web Civics was established to close a practical gap: standards bodies and Internet Governance forums alone were not producing enough deployable, people-centred software for civic and humanitarian use. That mission came before — and drives — the choice of Solid and CSS as an open starting point. CSS offered a solid general-purpose pod and protocol server; it did not, by itself, cover the richer needs of individuals and families, and across the Solid ecosystem there were still no implementations for organisations, small business and similar actors. Web Civics Databox is built to serve those missing surfaces.

Intent

Build and steward software that serves people and communities — not only commercial platform capture, and not only standards text without deployable civic tooling. Credits for Solid and CSS belong on this page; they do not demote the purpose or authorship of the Databox.

W3C public lists — heritage to read

These archives are part of the record of how WebID, credentials and the read-write / Solid line were formed. The project asks readers to consider early heritage, not only the most recent posts.

  • public-webid — WebID identity community
  • public-webpayments → public-credentials — credentials work that continued from the web-payments list
  • public-rww → public-solid — Read-Write Web community that became the Solid list
  • public-humancentricai — established and chaired by Timothy Holborn (continued until illness and homelessness prevented further chairing)
  • public-schema-gen — co-chaired
  • public-cogai — Cognitive AI community list

What Web Civics built here

Databox capabilities created in this project.

These are the substantive layers authored in this repository — the Mapping Smithy, governed exchange, IPMS, personal profile, CKAN bridge and related systems. CSS supplied the Solid HTTP runtime; the Databox model and these tracks are the project’s own work.

Shared shoulders

Web, RWW and Solid — foundations we honour.

Earlier open-web work made Solid possible. We acknowledge it; it does not author or own Web Civics Databox. Dates are approximate.

Upstream context (acknowledgement)
EraThreadWhy it matters here
1989–1990s World Wide Web Read-write hypertext vision; URLs and HTTP as shared substrate.
2000s–2010s Linked Data / Semantic Web RDF and shared identifiers for machine-readable web data.
~2010s RWW, WebID, credentials Authenticated read-write Linked Data, WebID and related credentials work — including W3C public lists whose heritage includes early definitional participation by a small group of people (see lists above).
~mid-2010s Databox servers & research Early deployed Databox / personal-store servers in the RWW–Solid line (e.g. databox.me) and related personal-data platform research such as Personal Data: Thinking Inside the Box (arXiv:1501.04737). Web Civics Databox continues that naming and problem space; it is not a claim of authorship over that paper.
~2015–2016 Crosscloud Personal data store / app-access precursor often cited before Solid; details from primary sources.
~2016 onward Solid Project Pods, apps, open protocol — the interoperability target this Databox implements against.
2019–2026 Community Solid Server Modular TypeScript Solid server (Inrupt, imec and contributors) — version 7.1.9 is this tree’s fork base.
