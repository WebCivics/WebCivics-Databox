Technical Architecture & Reference

Web Civics Databox: Open Protocols & Software.

Digital information is defined legally as Intellectual Property. Web Civics Databox is an open-standards, relationship-governed Read-Write Web server built on Node ≥ 24. It combines W3C Solid Linked Data protocols with the Mapping Smithy control plane, purpose-bound Relationship Databoxes, cryptographically signed receipts, ODRL policy governance, and the modular IPMS business suite.

Authorship & Heritage

Architected by Timothy Charles Holborn / Web Civics, advancing 25 years of human-centric data architectures, continuing and extending open W3C Solid and Community Solid Server (CSS) standards.

System Innovations

Enterprise & civic data exchange meets natural person stewardship.

Web Civics Databox bridges a foundational gap in the decentralized web. While earlier and foundational versions of Solid focused almost exclusively on generic personal storage pods without operational business software, Web Civics Databox advances the software stack to provide complete operational infrastructure for small businesses, community organisations, and civic bodies. This breakthrough solves the missing counterparty problem, enabling the bilateral exchange of verified records—such as digital receipts, orders, and personal credentials—between living human beings and local organisations.

Relationship Databox Model

Strict purpose-bound isolation: 1 Natural Person × 1 Program × 1 Opaque Container. Organisations interact through dedicated bilateral boundaries without gaining browsing rights to the person's private vault.

Mapping Smithy Control Plane

Declarative JSON API (/.databox/smithy) managing Institution Profiles, schema transformations, and event-driven data ingestion from external enterprise databases.

Verifiable Exchange & Receipts

Exact-byte commit pipeline with SHA-256 payload integrity, signed cryptographic receipts, and immutable append-only / supersede / tombstone audit records.

IPMS Operational Suite

60+ modular business applications advancing Solid to the commercial edge: POS, inventory, hospitality, logistics, facilities, and digital receipt issuance operating natively on linked data.

Personal Vaults & Guardianship Care

Personal data vaults supporting natural persons, family-scale governance, multi-generational guardianship responsibilities, and unconditional safe exits with standard W3C RDF export.

Pluggable Graph Engines & CKAN

Modular query infrastructure supporting in-process Oxigraph for SPARQL 1.1 querying, Web Civics Qualia for symbolic decision evidence, and automated CKAN open data publication.
