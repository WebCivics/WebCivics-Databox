Industry Provisioning & Module System

Operational software for small businesses & organisations.

IPMS provides the missing operational half of the Solid ecosystem. While earlier Solid implementations focused solely on personal pods—leaving businesses with no software to receive or issue records—IPMS equips small businesses, venues, and organisations with 60+ modular applications (point-of-sale, inventory, customer ordering, ticketing, and verifiable receipts) operating natively on linked data. This enables businesses and natural persons to engage in direct, bilateral record exchange under local law.

Org mobile apps

One WASM/PWA container, many profiles.

Instead of separate apps per purpose, a unified container fetches identity, features and permissions from IPMS at runtime based on the organisation’s vertical profile.

Waiter

Table-side order management — typically local-only network scope.

Driver

Delivery driver management — remote-capable where the profile allows.

Tradie

Trade / field-service profile for local job workflows.

Print

Print-shop operations bound to device and organisation scope.

Scorekeeper

Event scorekeeping with local-only enforcement via service worker.

Referee

Referee management for sports events under the same container model.

Per-install VC licensing

Each app install receives a Verifiable Credential licence binding app, organisation, device, scope and permissions. Network scope (local-only vs remote-capable) is enforced in the service worker.
